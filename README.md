## 설치 — 시즌 1을 이미 쓰고 있다면 (5분)

1. 시즌 1 구글 시트 → 확장 프로그램 → Apps Script → 내용을 지우고 이 저장소의 **`Code.gs`** 붙여넣기 → 저장
2. **배포 → 배포 관리 → ✏️(수정) → 버전: 새 버전 → 배포** (웹 앱 URL이 그대로 유지됨)
3. 깃허브에 새 저장소 `araho-earthmoon`을 만들고 이 폴더 파일을 모두 올린 뒤 **Settings → Pages → main 브랜치**
4. `index.html`의 `const API`에는 시즌 1과 같은 URL이 이미 들어 있습니다

`Code.gs`는 **시즌 1·2 겸용**입니다. 시즌 1 앱은 예전과 똑같이 동작하고, 시즌 2 기록만 `학생 S2` · `기록 S2` · `교신 S2` · `응답 S2` · `쿠폰 S2` · `S2 관측보고①~④` · `S2 관측추리` 탭에 따로 쌓입니다. 명단(콜사인)과 `설정`(GEMINI_KEY·PIN)은 함께 씁니다.

## 처음 쓰는 선생님 (재과만 배포용)

새 구글 시트 → Apps Script에 `Code.gs` 붙여넣기 → 웹 앱으로 배포(실행: 나 / 액세스: 모든 사용자) → URL을 `index.html` 맨 위 `API`에 붙여넣기 → `설정` 탭에 `GEMINI_KEY`, `PIN` 입력. 학교 이름은 `SCHOOL`, 하늘 시계의 위치·날짜는 `OBS_LAT`, `OBS_LON`, `EVENT_DAY`에서 바꿉니다. 다른 출판사 교과서라면 슬라이드의 쪽수 표기만 바꿔 쓰면 됩니다(성취기준 내용은 같음).
